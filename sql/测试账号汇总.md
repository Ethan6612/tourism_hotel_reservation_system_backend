## ⚠️ 注意事项

1. **生产环境修改密码**: 部署到生产环境前，请务必修改所有测试账号的密码
2. **不要删除测试账号**: 这些账号用于系统功能测试，建议保留
3. **角色权限配置**: 确保在系统中为三种角色正确配置了菜单和按钮权限
4. **数据隔离测试**: 重点测试商户只能查看自己的数据，普通用户只能查看自己的订单
5. **缓存清理**: 修改角色权限后，记得清理Redis缓存

## 🔧 如何创建新的测试账号

### 方法一：通过SQL直接插入
```sql
-- 创建新用户
INSERT INTO sys_user (user_name, nick_name, user_type, email, phonenumber, sex, password, status, create_by, create_time) 
VALUES ('testuser', '测试用户', '00', 'test@example.com', '13900000000', '0', 
        '$2a$10$7JB720yubVSZvUI0rEqK/.VqGOZTH.ulu33dHOiBE8ByOhJIrdAu2', '0', 'admin', NOW());

-- 获取新用户的ID
SET @new_user_id = LAST_INSERT_ID();

-- 分配角色（2=普通用户, 3=商户）
INSERT INTO sys_user_role (user_id, role_id) VALUES (@new_user_id, 2);
```

### 方法二：通过系统界面创建
1. 使用管理员账号登录
2. 进入"系统管理" -> "用户管理"
3. 点击"新增"按钮
4. 填写用户信息
5. 选择对应的角色
6. 保存
